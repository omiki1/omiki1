## ✨ Featured Projects

### [MediAtlas · 医学证据工作台](https://github.com/omiki1/medical_agentic_rag)

面向疾病知识图谱问答的医学知识工作台：**FastAPI + Vue 3** 双端，把疾病知识图谱、公开医学来源与对话上下文连接起来，让回答带上出处、检索与校验过程。

后端包含受限 Agent 规划、BM25 + Dense 混合检索、RRF 融合与 CrossEncoder 重排、分层记忆（窗口 / 摘要 / 语义 / Redis），并配套 Neo4j 图谱导出与完整的容器化部署栈。

`Python` · `FastAPI` · `Vue 3` · `Neo4j` · `Chroma` · `BM25 + Rerank` · `Docker`

[查看项目 →](https://github.com/omiki1/medical_agentic_rag) · 仅供学习与研究，未经临床验证
